# CGS3 AI — Global Repository Privacy & Community Scope Policy

**Policy ID:** GOV-REPO-PRIVACY-001  
**Effective:** 2026-11-19  
**Authority:** Founder, Speedlink3 AI Technologies  
**Applies to:** ChatGPT-GURU-Speedlink3-AI community coordination and any associated public community worker, workflow, or connector.

## 1. Non-negotiable rule: Private means Private

**ALL PRIVATE REPOSITORIES — WITHOUT EXCEPTION — ARE OUT OF SCOPE FOR THE CGS3 AI PUBLIC COMMUNITY AUTOMATION.**

The rule is categorical, **not project-specific**. It applies to every existing or future private repository in the organization, regardless of project name, owner, or subject matter.

No public-community workflow or agent may:

- Read, enumerate for content discovery, clone, fetch, index, summarize or analyze private repository files, issues, commits, pull requests, artifacts, history, or metadata for community coordination;
- Post private project names or contents into public Issues, announcements, build logs or community documentation;
- Connect private codebases to the public community coordination system, or automatically publish, mirror, convert or change visibility of any private repository;
- Read or share secrets, credentials, databases or unpublished security findings.

A founder-authorized **separate private project workflow** remains distinct from public community automation. Such work does **not** make its private resources eligible for community aggregation or publication.

## 2. Public MIT repositories share community governance

Every **public repository within this GitHub organization that explicitly uses the MIT License** is intended to use the same core CGS3 AI community rules:

- Openness to voluntary human contributions and constructive criticism.
- Issue triage, evidence requirements, transparent credit and review records.
- Bounded agent resource use and prohibitions on fake PASS, fake acknowledgments and unauthorized production changes.
- Human approval for privileged changes, protected merges and production operations.

**Scope eligibility is not automatic technical installation.** A newly published MIT repository must have its public visibility and MIT license verified, and must include a reviewed workflow configuration or opt in to the shared reusable workflow. The existing GitHub Action in the organization’s public `.github` repository currently operates **only on its own Issues**; it does not automatically dispatch across other repositories.

The organization’s public `.github` repository is a **community governance hub**; it may publish governance/coordination notices regardless of the license status of separate software repositories.

## 3. Fail-closed eligibility gate

Before onboarding any repository to community automation, verify:

1. The repository belongs to `ChatGPT-GURU-Speedlink3-AI`.
2. Its visibility is **public**; if private or visibility cannot be confirmed, **STOP**.
3. Its applicable repository license is **MIT**; if absent, different or unverified, **STOP and request governance review**.
4. The workflow is installed **within that eligible public repository** or called by an intentionally configured public repository workflow.
5. Workflow permissions are minimal and limited to approved Issue coordination; no private-repository token or cross-repository access is granted.
6. No production change, deployment, branch merge or source modification is implied by routine community coordination.

## 4. Acknowledgments and ownership

Anyone can propose, critique or review voluntarily on public eligible repositories. An automated label or comment means a *request*, not that ChatGPT, Google Search AI, Codex, GitHub Copilot, Antigravity IDE or any human has read, agreed, acted or received direct notification.
